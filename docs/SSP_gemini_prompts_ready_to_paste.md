# SSP Labels: all 27 image prompts, ready to paste into Gemini

Each prompt below already includes the style rules, plus the cut-out rules where needed. Copy one block, paste it into Gemini, send it, and save the result with the file name shown. You don't need to edit the images yourself: send them to me as they are and I'll remove the watermark and background, crop, compress and place them.

## How to run them

- **One prompt per message, one image at a time.** Don't paste several prompts together: Gemini merges or skips them, and you can't tell which image belongs to which slot.
- **Start a new Gemini chat for each group below.** Inside a group, stay in the same chat, so the product photo shows the same bottle or pack as its cut-out.
- If an image has readable words or a logo on it, reply in the same chat with: *"Same image, but make every bit of text on the label illegible abstract marks."*
- Download the full-size image and name it as shown (or just number it). Send them in batches whenever you like.
